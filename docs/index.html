Preparar el token
  1. En GitHub, crea un token de acceso personal de tipo fine-grained, o revisa uno existente.
  2. Selecciona únicamente compra-clara-datos y el permiso Contents: Read and write.
  3. Pega el token en este campo. No lo incluyas en archivos ni mensajes.
